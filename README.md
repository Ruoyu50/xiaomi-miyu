# 小咪密语

把任何中文变成只由九个可爱字组成的密文：

**小 咪 好 软 香 甜 棒 乖 喵**

打开 `index.html` 就能用，不需要安装任何东西。开启 GitHub Pages 后也可以直接在线访问。

## 示例

| 原文 | 密文（不填密钥） |
|---|---|
| 的的的 | 喵好喵好喵好 |
| 今天也要好好吃饭，晚上见！ | 41 个小咪字 |

## 原理

- 九个字依次代表 0 到 8，整套编码是**九叉霍夫曼编码**。
- 码表覆盖 6500 个常用汉字和中英文标点，按字频分配码长：越常用越短。“的”“是”只要两个字，罕见字要五到七个。按字频加权平均，每个汉字约 3.2 个小咪字。
- 所有码直接连在一起，中间没有分隔。任何一个码都不是另一个码的开头（前缀码），所以解码时从头往后读，读到完整的码就能确定是哪个字。
- 码表里没有的字（表情、生僻字、外文）先写一个转义码，再用七位九进制写出它的 Unicode 编号。

## 密钥（可选）

填了密钥时：

- 开头加 2 个随机字（盐），结尾加 2 个校验字。
- 用 SHA-256(密钥, 盐, 计数器) 生成伪随机数串，和码逐位相加后取模 9。
- 同一句话每次加密结果都不同；密钥不对时，校验不通过，会提示解不开（误判概率约 1/81）。

这是一个玩具级加密，适合好玩和传小纸条，不适合保护真正敏感的信息。

## 重新生成码表

```bash
pip install jieba
python3 tools/build.py <jieba 的 dict.txt 路径> tools/codes.json
```

`tools/build.py` 用 jieba 分词词典统计字频（并校正了“的”等虚词的频率），构造九叉霍夫曼树。生成的 `codes.json` 嵌入 `tools/template.html` 中的 `__TABLE__` 位置即得到页面。
